invoice-reconciler-java

The invoice reconciler written again in Java: exact BigDecimal money, immutable records, a runnable jar and JUnit 5 tests.

Why a second version

Java is the language many finance and enterprise systems are written in, so I wrote the reconciler again in Java 21 to show the same logic in a typed, compiled setting. It has no runtime dependencies (JUnit 5 is used for the tests) and it is built with Maven into a single runnable jar.

What is different from the Python version

  • Money is BigDecimal with two decimals, never double. 0.1 + 0.2 is exactly 0.30; there is a test for it.
  • Records (Invoice, Payment, Match, Result) make the data immutable and give equals and toString for free.
  • Main.run is separate from Main.main, so the whole program runs inside a test without System.exit and its output can be asserted.
  • Unreadable input is reported with its position, never guessed.

A test

Tests

22 JUnit 5 tests pass with mvn test (BUILD SUCCESS), including parameterized tests for the amount formats. Covered: amount and date formats, exact decimal arithmetic, field extraction, both matching passes, the one-payment-once rule, the currency check, the date window, the tolerance, and the whole program end to end on temporary files. A GitHub Actions workflow is included; it runs once the repository is on GitHub (it has not been run yet).

Stack: Java 21, Maven, JUnit 5, Git.
